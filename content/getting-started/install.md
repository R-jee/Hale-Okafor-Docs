## 1. Add the theme

1. In your Shopify admin, go to **Online Store → Themes**.
2. Add Hale Okafor from the Theme Store (**Visit Theme Store → Hale Okafor → Try theme** or **Add to theme library**). If you received the theme as a file, use **Add theme → Upload zip file** instead.
3. Hale Okafor appears in your **Theme library**. It stays unpublished until you publish it, so you can set it up while your current theme keeps running.

> Tip: Before you edit theme code, duplicate the theme (**⋯ → Duplicate**). Theme updates don't carry code edits over, and a copy lets you go back.

## 2. Open the theme editor

Click **Customize** next to Hale Okafor. The editor has three parts:

- **The page list** at the top: choose which page you're editing (Home page, Products → Default product, Collections → Default collection and so on).
- **The sidebar** on the left: the sections of the current page, in order, with their blocks. Click one to edit its settings; drag the handle to reorder; use the eye to hide it; **Add section** to add more. The brush icon at the bottom opens **Theme settings**.
- **The preview** in the middle: a live view of your store. Use the device switcher at the top to check mobile.

Changes are saved as a draft until you click **Save**. Customers see them only on the published theme.

## 3. Preview and publish

1. Click **Preview** (the eye at the top right) to browse the store as a customer.
2. When you're ready, go back to **Online Store → Themes** and click **Publish** on Hale Okafor.
