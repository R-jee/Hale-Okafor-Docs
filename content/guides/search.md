## Predictive search

The search icon opens a dialog. As the shopper types, results appear as index cards (number, name, measurements, price or Sold), then **Series**, **Journal** and **Pages** under their own tab dividers. Arrow keys move through results; Enter opens one.

Before typing, the dialog offers suggestions: browse by series, by glaze, and a few objects from the shelf.

Turn suggestions and prices on or off in **Theme settings → [Search](../theme-settings/search.html)**.

## Searching by object number

Store the object number as the variant SKU (`0142`), and searching `0142` finds the object directly.

## The search page

Results use the collection's Index view with the same filters and sort. With no results the page suggests materials and series to browse instead of a blank page.
