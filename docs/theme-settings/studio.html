Theme settings

Studio

Online Store → Themes → Customize → Theme settings → Studio.

GroupSettings

2. Object numbersShow object numbers, Number prefix, Digits

4. CollectionsDefault view, Shelf size range
5. Sold objectsSold objects in collections, Sold tag, Archive collection, Commission page, Edition label

#1General

How your objects are numbered, measured and kept on record. Measurements come from the product metafields described in the theme documentation; anything missing is simply left out.

    #2Object numbers

    • Show object numbersCheckboxshow_object_numbers

      Uses the atelier.object_number metafield, or the SKU when there is none.

      Default: On

    • Number prefixTextobject_number_prefix

      Shown before numbers taken from the SKU, for example "No. " or "AT-".

      Default: No.

    • DigitsRange sliderobject_number_padding

      Pads numbers taken from the SKU with leading zeros, so 42 shows as 0042.

      0–6 · Default: 4

    #3Measurements

    • UnitsSelectunits
      • Centimeters default
      • Inches
      • Both
    • Dimension linesSelectdimension_lines

      Measured lines drawn around product media and used as rules on the page.

      • Media and page rules default
      • Product media only
      • Off
    • Scale referenceSelectscale_reference

      The figure an object is drawn beside so customers can judge its size. Automatic picks one from the object height.

      • Automatic default
      • Hand
      • A4 sheet
      • Chair
      • Person
      • Coin
      • Off

    #4Collections

    • Default viewSelectcollection_view

      Shelf stands objects side by side at their true relative size. Index lists them as a catalogue. Customers can switch.

      • Shelf default
      • Index
    • Shelf size rangeRange slidershelf_max_ratio

      How many times taller the tallest object on a shelf may be drawn than the shortest. Lower values keep small pieces readable.

      2–10 · Default: 6

    #5Sold objects

    • Sold objects in collectionsSelectsold_display

      Sold objects keep their page, photos and record either way.

      • Keep in place with a sold stamp default
      • Show only in the archive collection
      • Hide from collections
    • Sold tagTextsold_tag

      Products with this tag are treated as sold even while they are still in stock.

      Default: archive

    • Archive collectionCollectionarchive_collection

      Where sold objects are kept on record. Linked from sold product pages.

    • Commission pagePagecommission_page

      Sold and made-to-order objects link here with the object number filled in.

    • Edition labelSelectedition_display

      Uses the atelier.edition_size metafield.

      • Edition of 12, 4 remain default
      • 4 available
      • Off
