Theme settings

Cart

Online Store → Themes → Customize → Theme settings → Cart.

GroupSettings
1. GeneralCart type
2. Often paired withProducts to suggest, Paired objects
3. OptionsShow estimated delivery, Show order note, Show discount code field, Gift wrap product, Show express checkout buttons

#1General

  • Cart typeSelectcart_type

    The drawer opens over the current page after adding to cart. The page option sends shoppers to the cart page.

    • Drawer default
    • Page

#2Often paired with

  • Products to suggestSelectcart_upsells

    One object shown under the packing list. Complementary uses the custom.complementary metafield, then Shopify's complementary products.

    • None
    • Recommendations default
    • Selected products
  • Paired objectsProductscart_upsell_products

#3Options

  • Show estimated deliveryCheckboxcart_show_delivery_estimate

    Uses the timings in Theme settings → Shipping and delivery. Hidden when nothing in the cart ships.

    Default: On

  • Show order noteCheckboxcart_show_notes

    Default: Off

  • Show discount code fieldCheckboxcart_show_discount

    Shoppers can also enter codes at checkout.

    Default: On

  • Gift wrap productProductcart_gift_wrap_product

    Create a product for gift wrapping and select it to show an "Add gift wrapping" option in the cart.

  • Show express checkout buttonsCheckboxcart_show_express_checkout

    Shows the express payment methods enabled in your payment settings, such as Shop Pay or PayPal.

    Default: On
