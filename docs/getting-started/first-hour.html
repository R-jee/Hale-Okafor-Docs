Getting started

Your first hour

A checklist that takes a fresh install to a store you'd be happy to show: brand, type, the studio record, menus, the home page and the main templates.

#1. Logo and favicon

Theme settings → Logo and favicon

  • Upload your Logo and set Logo width on desktop. Add a Mobile logo if your desktop logo is wide.
  • Under Logos by language, add a different logo for some languages (for example a logo set in Arabic script for Arabic and Urdu). See Logos by language.
  • Upload a Favicon at least 32 × 32 px.

#2. Colors

Theme settings → Colors

Hale Okafor works with four color schemes, each a set of colors that work together:

SchemeUsed for
Card stockThe main page background: off-white paper and dark ink
KilnThe dark ground: the home page opening, the firing, films, the footer
PlateA tinted ground for figures, spreads and the archive
InkInverted: the commission form and dark panels

Sections and blocks pick a scheme, so changing a scheme changes everywhere it's used. Keep text clearly readable on its background.

#3. Type

Theme settings → Typography

Hale Okafor has three type voices: Headings (a display face for names and titles), Body (for reading) and Record (a monospace face for object numbers, measurements, prices and labels). Pick each from Shopify's font library; bold and italic load automatically.

#4. The studio record

Theme settings → Studio is where the object record is set up for your studio:

  • Object numbers: show them, choose a Number prefix (No., HO-, AT-24-) and how many Digits (0142).
  • Measurements: Units (centimeters, inches or both), Dimension lines on photos, and the default Scale reference for scale drawings.
  • Collections: the Default view (shelf or index) and the Shelf size range (how much taller the tallest object may stand than the smallest).
  • Sold objects in collections: keep them in place with a sold stamp, show them only in the archive collection, or hide them; the Sold tag, the Archive collection and the Commission page that sold objects link to.

#5. Menus

Content → Menus in the Shopify admin.

  • Main menu is the header's label strip. Nest links to make dropdowns. A collection link shows its object count beside it automatically.
  • Footer columns each use a menu; see the Footer section.

#6. The home page

Open Home page in the editor. It starts with the demo arrangement: Kiln stage → Film arch → Catalogue contents → Kiln firing → Shelf → Object record → Wall text → Catalogue spreads → Sale room → Making log → Materials index → Glaze matcher → Plate → Archive → Maker → Release record → Journal notes.

Point each section at your own products, collections and images. Remove what you don't need; every section works on its own.

#7. Product and collection pages

  • Products → Default product: the Product information section holds the record's blocks. Reorder or remove them. Most read from metafields, so fill in Product records next.
  • Collections → Default collection: choose the filter layout, columns, the banner and the default view.

#8. Cart and delivery

  • Theme settings → Cart: drawer or page, Often paired with suggestions, order note, discount field, gift wrap and express checkout buttons.
  • Theme settings → Shipping and delivery: processing time, fastest and slowest delivery and the same-day cut-off. These drive the estimated delivery dates on products and in the cart.

#9. Check mobile, then publish

Switch the editor to mobile and walk through the home page, a product, a collection and the cart. Then publish from Online Store → Themes.
