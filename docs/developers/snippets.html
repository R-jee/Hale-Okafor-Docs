#dimensions

Formats an object's measurements from the atelier.height, atelier.width and atelier.depth dimension metafields, in the units chosen in Theme settings → Studio. Outputs nothing for measurements that are missing, so every caller degrades on its own.

Formats:

  • inline: "24 × 18 × 18 cm" (height × width × depth, whichever exist)
  • rows: one ledger row (<tr>) per measurement, for the specification table
  • axis: one measurement ("24 cm"), chosen with axis
  • cm: one raw measurement in centimeters (height unless axis says otherwise), unformatted, for scale drawings and the shelf (empty when unknown)
ParameterTypeDescription
productobjectThe product
format optionalstringinline (default), rows, axis or cm
axis optionalstringheight (default), width or depth, for the axis and cm formats
{% render 'dimensions', product: product, format: 'axis', axis: 'width' %}

#facets-filters

Storefront filters (Search & Discovery) for a collection or search. Each filter is a <details> disclosure of plain form fields, so filtering works without JavaScript.

  • List filters: checkboxes or pills (Filter style), swatches with names or as a swatch grid, images. Past the "values shown" limit the rest sit behind "Show more"; long lists get a search box.
  • Yes/no filters (boolean): switches.
  • Price: a two-handle slider, From/To fields and optional quick ranges ("Under $50").

Each filter is set as a tab of the catalogue index (numbered I, II, III…) and drawn by kind:

  • stamps: availability, as two ink stamps (inked once chosen)
  • glaze: colour, glaze or finish values (or any swatch filter), as glazed test tiles
  • tags: other lists, as hanging specimen tags, punched and stamped once chosen
  • switch: yes/no filters
  • ruler: price, the slider drawn as a measuring rule with tags showing the chosen span
ParameterTypeDescription
resultsobjectThe collection or search object (anything with filters)
id_prefixstringUnique prefix for field ids (the filters render in the sidebar or bar, and the drawer)
collapsed optionalbooleanStart every filter closed (horizontal bar dropdowns)
options optionalobjectThe results section's settings: filter_style (checkbox | pills), swatch_style (label | grid), values_limit, filter_search, price_presets, filters_open (two | all | active)
{% render 'facets-filters', results: collection, id_prefix: 'Sidebar', options: section.settings %}

#product-card

Renders a product as an object on the shelf: its photo in a 4:5 plate (the second photo crossfades in on hover), standing on the shelf's baseline, then the object number, name, measurements and price in the record face, and a Sold stamp when it has sold. The same markup is laid out as a catalogue row in the Index view (CSS only, html[data-results-view] or the grid's default). The whole card is clickable through one link (the title), so keyboard and screen reader users meet one tab stop per product, plus quick add when shown.

Relative height (ADR-011): shelf_max is the tallest atelier.height on the page in centimeters; a measured bar beside the measurements is drawn at height ÷ shelf_max, never below 1 ÷ the Studio shelf size range, so sizes compare at a glance while every photo keeps the same frame.

Layout row is the compact version for complementary products and cart upsells: thumbnail, number, title, variant, price and an add button, inside an <li>. It carries the first available variant and its price, so <product-recommendations> can add it alone ([data-quick-add]) or as part of a bundle ([data-bundle-item]). Products with options link to the product page instead of adding a guessed variant. Card and row CSS (component-product-card.css, component-recommendations.css) is linked once in the layout head (ADR-080), not here, so a grid doesn't repeat the <link> per card.

eager optionalbooleanLoad the image immediately without raising its priority (rest of the first row)
event_context optionalstringStandard event context for product views (collection | search | recommendation)
layout optionalstringcard (default) | row
shelf_max optionalnumberThe tallest object height on the shelf, in cm (see results-grid)
